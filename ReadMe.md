注意：

在后续测试中发现了一个非致命bug

即：当页面处于黑夜主题时，进行切换页面或者刷新页面，再次点击切换主题按键。会导致无法正常切换成白天主题，即使切换或者刷新页面，其他页面也会维持这个错误。除非进行切换白天主题后再刷新的操作，才可再次正常切换主题。只影响用户在黑夜主题时切换成白天主题的体感。并不影响正常使用黑夜主题和白天主题。故在下次更新后修复。
